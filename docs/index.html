弱熵的统一规律

十三年，十一个案例，一个形状 —— 一门可以自己跑的课

先看这个

比特币的私钥安全不是一件事，是三道门串在一起：①造钥匙 ②存钥匙 ③用钥匙。

全世界讨论的是门 2（设备会不会被攻破）和门 3（签名的时候会不会被骗）。
但钱主要是从门 1 丢的 —— 从造钥匙那一步丢的。

原因只有一个：只有门 1 的失败是静默的。
门 2 失败你知道，东西丢了。门 3 失败你看得见，屏幕上地址不对。
门 1 失败什么都看不出来 —— 钱包正常，余额对，能收能发，二十四个词好好躺在抽屉里，
直到某一天余额是 0。

这门课讲的就是门 1。十三年，十一个独立案例，十一个不同的团队。
它们有一个共同点，而那个共同点比「随机数很难」具体得多，也有用得多。

免责：本课程复现的全部是已被公开披露并已修复的历史缺陷，用于教学。所有实验使用固定的 demo 种子，不生成任何真实钱包，不联网，不查询任何地址。Coldcard 相关材料全部来自外部公开出处。

怎么开始

整套代码只用 Python 标准库，没有任何依赖。椭圆曲线、BIP39、BIP32、MT19937 全部在仓库里从头实现 —— 因为这门课的要点就是不要相信包装层， 包括我写的那些。

git clone https://github.com/aaron-recompile/weak-entropy-lessons.git && cd weak-entropy-lessons

克隆下来。

./run_all.sh -q

把十二课全部跑一遍，确认每一课都真的能跑出结果（约 40 秒）。

python3 lessons/01_milk_sad/milk_sad.py

从第一课开始。它会逐字复现那二十四个词，然后在几秒内反推出一把钥匙。

这门课的三条规矩

  1. 大白话在前，细节在后。每课开头那个方框几乎不含数字 —— 只想拿一个心智模型就走，看它就够了。
  2. 每个数字都能指回出处，而且带证据分级。 标「弱」的数字不要单独使用，哪怕它是流传最广的那个。
  3. 能跑的就不要只是读。十二课里有十一课可以在一台笔记本上跑完， 包括用真的编译器复现 Coldcard 那个链接期失效。
