同一段代码，三个弱钱包范围

PHPCoinAddress · 2013–2018

大白话

前面四课的受害者都是个人用户。这一课的受害者是基础设施。

2013 年有一个 PHP 库，给网店在服务器上批量生成收款地址用。
每个来买东西的顾客拿到一个新地址，而那个地址的私钥是用 mt_rand() 生成的。

发布几个月后就有人在论坛上公开点名：「这个脚本生成的私钥不安全，第 240 行用了 mt_rand」。

这是全部十一个案例里最快的一次发现。然后用量持续了好几年。

因为用它的人根本不读那个论坛。

这一课还有一个很少被讲的复杂度：PHP 在二十年里至少改了三次 mt_rand() 的底层行为。
所以同一段代码，在不同版本的 PHP 上生成完全不同的钥匙 —— 不是一个弱空间，是一族。

往下一层

差一个字母

PHP 的 Mersenne Twister 和标准的差在一行上。C 源码里是两个宏：

// 正确（MT_RAND_MT19937）
#define twist(m,u,v)     (m ^ (mixBits(u,v)>>1) ^ (-(int32_t)(loBit(v)) & 0x9908b0df))
                                                                   ^^^^
// PHP 自己的（MT_RAND_PHP）
#define twist_php(m,u,v) (m ^ (mixBits(u,v)>>1) ^ (-(int32_t)(loBit(u)) & 0x9908b0df))
                                                                   ^^^^

u 和 v。十三年里，全世界 PHP 生成的随机数都走的是下面那条。

课程代码两个模式都实现了，跑一下会看到： 同一个种子，一整轮 624 个输出里约一半不同。 一半不同就已经是两个完全不相交的弱钱包空间，研究者要分别枚举。

证据说明：这段实现是按 PHP 的 C 宏写的，没有和真实 PHP 引擎交叉验证过 （本机没装 PHP）。机理（差一个 u/v）是有一手出处的； 「本实现与真实引擎逐值一致」这件事没有。你装了 PHP 可以一行核对：

php -r 'mt_srand(42, MT_RAND_PHP); echo mt_rand(),",",mt_rand();'

自己跑一下

python3 lessons/06_php_mt_rand/php_mt_rand.py

两个模式并排跑，数出一轮里有多少个输出不同。
